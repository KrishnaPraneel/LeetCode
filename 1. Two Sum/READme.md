1. Two Sum

Approach 1:
My first approach is brute force. Since I need to find two numbers whose sum equals the target, I can check every possible pair using two nested loops. The outer loop picks the first number, and the inner loop checks all remaining numbers. If the sum of the pair equals the target, I return their indices. This guarantees finding the answer because every pair is examined.
